<objective>
Implement the Notifications service as the first real MassTransit consumer in the system, wired with the idempotent inbox pattern. The CatalogSeededConsumer receives CatalogSeeded events and the inbox deduplicates redelivered messages by MessageId. An integration test using the MassTransit InMemory test harness proves deduplication.

Purpose: Delivers INF-02 (idempotent inbox). Demonstrates that the outbox/inbox pattern works end-to-end and that duplicate message delivery (a real ASB guarantee) does not produce duplicate processing.

Output: Notifications service with NotificationsDbContext (inbox tables), CatalogSeededConsumer, EF migrations, a DbInitializer, and an xUnit integration test proving the D-14 forced redelivery scenario.
</objective>
