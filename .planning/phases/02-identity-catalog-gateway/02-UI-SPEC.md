## Spacing Scale

Declared values (all multiples of 4, mapped to Angular Material spacing conventions):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip inner padding, badge spacing |
| sm | 8px | mat-form-field label gap, mat-chip margin, button icon gap |
| md | 16px | Default card padding, form field spacing, toolbar content padding |
| lg | 24px | Card margin, section gap between form groups |
| xl | 32px | Page content horizontal padding (desktop), grid gap between product cards |
| 2xl | 48px | Major section breaks, empty-state vertical centering padding |
| 3xl | 64px | Page-level top/bottom padding on /catalog and /product/:id |

Exceptions:
- Touch targets (mat-button, mat-icon-button): minimum 44px height — enforced by Angular Material's density 0 default; do not override to a smaller density.
- mat-toolbar height: 64px (Material default) — not adjusted.

## Typography

Using Angular Material's typography system (`mat-typography`). Declare exactly 4 roles:

| Role | Material Level | Size | Weight | Line Height | Usage |
|------|---------------|------|--------|-------------|-------|
| Body | `body-1` | 16px | 400 (regular) | 1.5 | Product descriptions, form labels, body copy |
| Label | `body-2` | 14px | 500 (medium) | 1.43 | Price labels, stock badge text, chip labels, captions |
| Heading | `subtitle-1` / `h6` | 20px | 500 (medium) | 1.4 | Product card titles, section headings, page sub-titles |
| Display | `headline-5` / `h4` | 28px | 400 (regular) | 1.2 | Product detail page product name, /login and /register page titles |

Weight constraint: exactly 2 weights in use — **400 (regular)** and **500 (medium)**. No 700/bold in component-level styles; Angular Material toolbar and button use their own internal weight rules.

Font stack: `Roboto, "Helvetica Neue", Arial, sans-serif` (Angular Material default — do not override).

## Color

Angular Material indigo-pink theme. Expressed as the 60/30/10 model:

| Role | Material Token | Approximate Hex | Usage |
|------|---------------|-----------------|-------|
| Dominant (60%) | `$mat-background` surface | `#FAFAFA` (grey-50) | Page background, app shell background |
| Secondary (30%) | `mat-card` surface / toolbar fill | `#FFFFFF` (white) | mat-card backgrounds, mat-toolbar, mat-sidenav if used |
| Accent (10%) | `$accent` — pink A200 | `#FF4081` | Reserved for specific elements listed below |
| Destructive | `$warn` — red 700 | `#D32F2F` | Error states on mat-form-field (validation), destructive action text only |

Accent (`#FF4081`) reserved for exactly these elements:
1. "View Details" button on product card (mat-raised-button color="accent")
2. "Sign In" submit button on /login (mat-raised-button color="accent")
3. "Create Account" submit button on /register (mat-raised-button color="accent")
4. Active/selected category chip in the catalog filter chip-listbox

Primary color (`$primary` — indigo 500 `#3F51B5`) used for:
- mat-toolbar background
- mat-paginator active page indicator
- Focused mat-form-field underline/outline

Destructive (`#D32F2F`) used only for:
- mat-form-field `mat-error` validation messages
- No destructive actions (delete/remove) exist in Phase 2 scope

## Component Inventory

All components use Angular Material standalone imports. Each component declares only the Material modules it directly uses.

### Nav Toolbar (`app-shell` / `AppComponent`)

- Component: `mat-toolbar` with `color="primary"` (indigo background, white text)
- Left: app logo text "eCommerce" as a `routerLink="/"` anchor inside the toolbar
- Right slot: nav links (`/catalog` as mat-button), conditional login/logout button
  - Unauthenticated: "Sign In" button (mat-button, routerLink="/login")
  - Authenticated: username display + "Sign Out" mat-button (calls OIDC logout)
- No mat-icon in toolbar for Phase 2 (logo is text only)

### Product Card (`ProductCardComponent`)

- Outer: `mat-card` with `appearance="outlined"`
- Image slot: `mat-card-image` — `<img>` with `[src]="product.imageUrl"` and `alt="{{product.name}}"`. Fallback: grey 200 placeholder div (150px height) when `imageUrl` is null/empty.
- Content: `mat-card-content`
  - Product name: `<h3>` (heading role, 20px/500)
  - Price: `<p class="price">` — formatted as currency (Angular `CurrencyPipe`, USD, no decimals for whole amounts)
  - Stock badge: `<mat-chip>` inside `mat-chip-set` — "In Stock" (green, `color="primary"`) or "Low Stock" (yellow, no color attr) or "Out of Stock" (grey, disabled appearance) based on stock quantity thresholds: >10 = In Stock, 1–10 = Low Stock, 0 = Out of Stock
- Actions: `mat-card-actions align="end"` — single "View Details" `mat-raised-button color="accent"` with `[routerLink]="['/product', product.id]"`

### Product Grid (`CatalogListComponent` at `/catalog`)

- Layout: CSS grid — `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`, gap = 32px (xl token)
- Page-level horizontal padding: 32px (xl) desktop, 16px (md) mobile (breakpoint: 600px)
- Filter row above grid: `mat-chip-listbox` for category selection (single-select). Chips: "All" (default selected) + one chip per distinct category returned by the API. On chip change: update signal, re-fetch products.
- Pagination: `mat-paginator` below grid — `pageSize=12`, `pageSizeOptions=[12, 24, 48]`. On page change: update signal, re-fetch with new offset.
- Loading state: `mat-progress-bar mode="indeterminate"` at top of grid area (not full-page spinner)
- Empty state: see Copywriting section

### Product Detail (`ProductDetailComponent` at `/product/:id`)

- Layout: two-column on desktop (>960px): left col 40% image, right col 60% details. Single column on mobile.
- Hero image: `<img>` 100% width, `aspect-ratio: 4/3`, `object-fit: cover`. Fallback: grey 200 div.
- Details column:
  - Product name: Display role (28px/400) as `<h1>`
  - Category: Label role (14px/500) as `<p class="category">` with mat-chip (non-interactive)
  - Price: Heading role (20px/500), currency formatted
  - Stock badge: same chip logic as product card
  - Description: Body role (16px/400), `<p>` — supports multi-paragraph via `\n` split
  - "Add to Cart" button: `mat-raised-button color="primary"` — **disabled and labelled "Coming in Phase 3"** for Phase 2. No click handler.
- Back navigation: `mat-button` with mat-icon `arrow_back` — "Back to Catalog" (routerLink="/catalog")

### Login Page (`LoginComponent` at `/login`)

- Layout: centered card, max-width 400px, vertically centered on viewport
- Title: Display role (28px/400): "Sign In"
- Subtitle: Body role (16px/400): "Welcome back. Sign in to continue."
- Single `mat-card` with `mat-card-content`:
  - Info `mat-hint` below form: "You'll be redirected to complete sign in securely."
  - Single "Sign In" button: `mat-raised-button color="accent"` full-width
  - On click: calls `angular-auth-oidc-client` `authorize()` to initiate the PKCE redirect. No email/password fields on this page — auth happens on the OpenIddict consent/login page.
- Below card: "Don't have an account?" + "Register" anchor (routerLink="/register") in Label style

**Rationale:** D-01 establishes full OIDC auth code + PKCE flow. Angular redirects to `/connect/authorize` on the Identity service. The /login page is a redirect trigger, not a credentials form.

### Register Page (`RegisterComponent` at `/register`)

- Layout: centered card, max-width 400px, vertically centered on viewport
- Title: Display role (28px/400): "Create Account"
- Subtitle: Body role (16px/400): "Register to start shopping."
- `mat-card` with `mat-card-content` containing a reactive form:
  - Email field: `mat-form-field appearance="outline"` — `matInput type="email"` with label "Email address". Validators: required, email format.
  - Password field: `mat-form-field appearance="outline"` — `matInput type="password"` with label "Password". Validator: required, minLength(8). Toggle visibility: `mat-icon-button` suffix using icon `visibility` / `visibility_off`.
  - Confirm Password field: `mat-form-field appearance="outline"` — `matInput type="password"` with label "Confirm password". Cross-field validator: must match password.
  - Submit: `mat-raised-button color="accent"` full-width — "Create Account". Disabled while form invalid or submission in progress.
  - Loading indicator: button shows `mat-spinner diameter=20` inline when submitting (replaces button text).
- Below card: "Already have an account?" + "Sign In" anchor (routerLink="/login") in Label style
- On success: navigate to `/login` to trigger PKCE flow

### Callback Page (`CallbackComponent` at `/callback`)

- Minimal — no visible UI beyond a centered `mat-spinner` and label "Completing sign in..."
- `angular-auth-oidc-client` handles token exchange automatically via `checkAuth()`
- On completion: `router.navigate(['/catalog'])`
- On error: display inline error message (see Copywriting) + "Try Again" button (routerLink="/login")

## Interaction States

### Form Fields (all mat-form-field instances)

| State | Visual |
|-------|--------|
| Default | Grey outline, label floating |
| Focused | Primary color (indigo) outline + label |
| Valid (touched) | No additional indicator — avoid green "success" states |
| Invalid (touched) | Warn color (red) outline + `mat-error` message below |
| Disabled | 38% opacity, no pointer events |

### Buttons

| State | mat-raised-button behavior |
|-------|---------------------------|
| Default | Filled, accent/primary color |
| Hover | Elevation shadow increase (Material default ripple) |
| Active | Ripple effect (Material default) |
| Disabled | 38% opacity, cursor default, no ripple |
| Loading | Replaced with inline spinner, disabled |

### Product Cards

| State | Visual |
|-------|--------|
| Default | Outlined mat-card |
| Hover | `mat-elevation-z4` shadow — apply via `(mouseenter)` / `(mouseleave)` class toggle |
| Out of Stock | Card opacity 0.7, "View Details" button disabled |

## Signal State Contract

| Feature | Signal | Type | Source |
|---------|--------|------|--------|
| Catalog | `products` | `Signal<Product[]>` | HTTP GET /api/catalog/products |
| Catalog | `isLoading` | `Signal<boolean>` | set true before fetch, false after |
| Catalog | `selectedCategory` | `Signal<string \| null>` | chip-listbox selection, null = "All" |
| Catalog | `currentPage` | `Signal<number>` | mat-paginator page index (0-based) |
| Catalog | `totalCount` | `Signal<number>` | from API pagination response |
| Product detail | `product` | `Signal<Product \| null>` | HTTP GET /api/catalog/products/:id |
| Product detail | `isLoading` | `Signal<boolean>` | HTTP loading state |
| Auth | `isAuthenticated` | `Signal<boolean>` | from angular-auth-oidc-client |
| Auth | `userData` | `Signal<UserData \| null>` | from angular-auth-oidc-client |

Use `computed()` for derived values (e.g. stock badge label derived from `product().stockQuantity`). Do not use BehaviorSubject or Observable state in components — route resolver or service method returns `toSignal(httpCall$)`.

## Accessibility Contract

- All `<img>` elements carry descriptive `alt` text. Product image alt: `"Photo of {product.name}"`. Fallback placeholder: `alt=""` (decorative).
- All form fields use `<label>` via `mat-label` (Angular Material wires `for` attribute automatically).
- Color is not the sole indicator of stock status — stock badge includes text ("In Stock", "Low Stock", "Out of Stock") in addition to chip color.
- Interactive elements meet minimum 44px touch target (Angular Material density 0 default).
- Error messages are announced via `aria-live` — Angular Material `mat-error` handles this automatically.
- Focus management on /callback: after OIDC redirect completes and navigation to /catalog occurs, Angular Router sets focus to the new route content area (standard Angular Router behavior).
