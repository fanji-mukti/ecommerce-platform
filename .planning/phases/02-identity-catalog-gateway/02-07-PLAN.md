<objective>
Fix the AppHost crash that blocks all UAT. In Aspire 10, calling WithEndpoint(name: "http", port: X, targetPort: X) on a non-container project resource is invalid when port equals targetPort — Aspire DCP cannot bind both to the same port. The fix is to replace every WithEndpoint(name: "http", ...) pattern with WithHttpEndpoint(port: X), and remove the duplicate http endpoint on the Payments service.

Purpose: Gap 1 — AppHost crashes before any service starts, blocking all 6 UAT scenarios. This is the highest-priority fix.
Output: A working AppHost/Program.cs that allows all services to start under `dotnet run --project src/ecommerce.AppHost`.
</objective>
