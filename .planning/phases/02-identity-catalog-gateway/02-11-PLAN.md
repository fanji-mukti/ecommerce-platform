<objective>
Fix Gap 8: Three Angular components inject HttpClient directly and own their own HTTP call implementations. The API URL /api/catalog/products is duplicated across CatalogListComponent and ProductDetailComponent. There is no service layer — HTTP concerns are mixed into the presentation layer.

Fix: Create CatalogService (getProducts, getProduct) and IdentityService (register) as @Injectable services in src/app/core/services/. Update the three components to inject the respective service instead of HttpClient. All HTTP logic, URL construction, and response typing moves into the service classes.

Purpose: Centralizes API URLs, enables easy mocking in component tests (service stub vs HttpClient mock), and establishes the service layer pattern that Cart and Orders features will extend in later phases.
Output: Two new service files; three updated components; Angular build and Vitest pass.
</objective>

      import { Injectable, inject } from '@angular/core';
      import { HttpClient } from '@angular/common/http';
      import { Observable } from 'rxjs';
      import { Product, PagedResult } from '../../shared/models/product.model';

      @Injectable({ providedIn: 'root' })
      export class CatalogService {
        private http = inject(HttpClient);

        getProducts(page: number, pageSize: number, category?: string | null): Observable<PagedResult<Product>> {
          let url = `/api/catalog/products?page=${page}&pageSize=${pageSize}`;
          if (category) {
            url += `&category=${encodeURIComponent(category)}`;
          }
          return this.http.get<PagedResult<Product>>(url);
        }

        getProduct(id: string): Observable<Product> {
          return this.http.get<Product>(`/api/catalog/products/${id}`);
        }
      }
