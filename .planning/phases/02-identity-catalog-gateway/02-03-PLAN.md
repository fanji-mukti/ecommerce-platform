<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GET /products (query params) | Untrusted page, pageSize, category values from browser/client |
| MassTransit outbox | Catalog DB → ASB; failure mode is message stuck in OutboxMessage table |
| EF Core queries | User-supplied category filter must never become raw SQL string concatenation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | SQL injection via category query param | mitigate | EF Core parameterized LINQ queries (p.Category == category) — never string-concatenated SQL; EF Core translates to parameterized WHERE clause |
| T-02-03-02 | Denial of Service | Unbounded pageSize allows huge DB reads | mitigate | pageSize clamped to max 100 in ProductsEndpoints before query execution |
| T-02-03-03 | Information Disclosure | EF Core exception messages in 500 responses | mitigate | All error paths return Results.Problem("Internal error") — never raw Exception.Message |
| T-02-03-04 | Tampering | MassTransit floating version resolves to v9 (commercial) | mitigate | All three MassTransit packages pinned at Version="8.3.6" in csproj |
| T-02-03-05 | Tampering | CatalogSeeded with Guid.Empty MessageId breaks inbox deduplication | mitigate | DbInitializer explicitly sets MessageId = Guid.NewGuid() — never Guid.Empty |
| T-02-03-SC | Tampering | NuGet package installs | mitigate | All packages pre-audited in RESEARCH.md Package Legitimacy Audit; MassTransit 8.3.6 confirmed Apache-2.0 |
</threat_model>
