<objective>
Extend the existing `OrderStateMachine` (built in Phase 3, ADR-0005) to orchestrate the full checkout saga: publish `AuthorisePayment` on order creation, react to `PaymentAuthorised`/`PaymentFailed` (CHK-03), react to `FulfillmentFailed` with a refund-and-cancel compensation (CHK-04), and enforce a configurable saga timeout via MassTransit `Schedule`/`Unschedule` (CHK-05). This is backend saga logic only — no HTTP endpoints yet (plan 04-03) and no real Payments consumer yet (plan 04-04); correctness is proven entirely via the existing in-memory saga unit-test harness.

Purpose: Make the saga state machine the single, inspectable source of truth for checkout orchestration and compensation, per ADR-0005 (orchestration, not choreography).
Output: Extended `OrderStateMachine`, `Order` aggregate, `OrderReadModel`/`OrderReadModelProjector`, new `CheckoutOptions`/`CheckoutTimeoutExpired`, EF migration, extended unit test suite, ADR-0009.
</objective>
