<objective>
Close 05-VERIFICATION.md/05-REVIEW.md's WR-03 warning gap: `order-detail.component.ts`'s polling subscription (`interval(1500).pipe(switchMap(...), takeWhile(...), takeUntilDestroyed(...))`) has no `catchError` recovery. A single transient HTTP error (network blip, transient 5xx) on any poll tick causes the inner observable produced by `switchMap` to error, which propagates through `takeWhile`/`takeUntilDestroyed` and terminates the entire `interval` subscription — polling stops permanently for the rest of the component's lifetime, silently (the existing `error: () => {}` handler swallows it), leaving the user staring at a stale, possibly non-terminal status with no way to recover short of a full page reload.

This is lower priority than CR-01/WR-02 per the gap-closure brief and is included here as a small, targeted, self-contained fix — no new UI element or copy is introduced (05-UI-SPEC.md's checker sign-off is still pending; this plan intentionally avoids expanding that surface).

Purpose: Make a transient polling error self-heal on the next 1.5s tick instead of permanently killing live status updates for the rest of the page's lifetime.
Output: A `catchError` recovery wrapped around the inner poll request inside `startPolling`, plus a regression test proving the polling loop survives a transient error and continues to reach a terminal status.

```typescript
const ORDER_DETAIL_TERMINAL_STATUSES = ['Fulfilled', 'Cancelled', 'Failed'];

export class OrderDetailComponent implements OnInit {
  private route = inject(ActivatedRoute);
  private ordersService = inject(OrdersService);
  private destroyRef = inject(DestroyRef);

  order = signal<OrderDetail | null>(null);
  isLoading = signal<boolean>(false);
  notFound = signal<boolean>(false);

  isShipping = computed((): boolean => this.order()?.status === 'Paid');

  ngOnInit(): void {
    const id = this.route.snapshot.params['id'];
    if (!id) { this.notFound.set(true); return; }
    this.isLoading.set(true);
    this.ordersService.getOrder(id).subscribe({
      next: (order) => {
        this.order.set(order);
        this.isLoading.set(false);
        this.startPolling(id);
      },
      error: () => { this.isLoading.set(false); this.notFound.set(true); },
    });
  }

  private startPolling(id: string): void {
    interval(1500)
      .pipe(
        switchMap(() => this.ordersService.getOrder(id)),
        takeWhile((order) => {
          this.order.set(order);
          return !ORDER_DETAIL_TERMINAL_STATUSES.includes(order.status);
        }, true),
        takeUntilDestroyed(this.destroyRef),
      )
      .subscribe({
        next: () => {},
        error: () => {},
      });
  }
}
```
